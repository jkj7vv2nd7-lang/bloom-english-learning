# Bloom English

物語・音声・間隔反復で英語を身につける、Next.js 製の学習アプリです。1日の目標や受験コースを選び、意味・リスニング・スペルの練習、レベル診断、週ごとの進捗確認ができます。

## 起動方法

Node.js 22.13 以降（`node:sqlite` 対応）を用意し、プロジェクトのフォルダで初回セットアップを実行します。

```bash
npm install
npm run db:init
npm run db:seed
npm test
npm run dev:3010
```

ブラウザーで http://localhost:3010 を開きます。`db:init` はスキーマ作成、`db:seed` はJSONの語彙・ストーリー投入です。seedはupsertで再実行でき、語彙は500件単位のチャンクで処理します。JSONを更新した後も `npm run db:seed` で再投入できます。

DBファイルは `data/learning.sqlite` に作成されます。`DATABASE_PATH` 環境変数で保存先を変更できます。語彙一覧の検索はSQLite FTS5、レベル/進捗はインデックス付きSQLで絞り込み、単語帳はサーバー側で25語ずつページネーションします。進捗はブラウザーごとの匿名学習者IDと一緒にSQLiteへ保存され、従来のlocalStorage進捗があれば初回に移行します。

開発サーバーはポート3010固定です。製品用ビルドは `npm run build`、ビルド後の起動は `npm run start:3010` です（ポート3010を別のアプリが使用中の場合はそのアプリを終了してください）。従来の `npm run dev` / `npm run start` も利用できます。

## できること

- 中学・高校レベルを想定したサンプル語彙を、レベル・重要度付きで収録
- 物語中の強調語句を選ぶと、日本語の意味や例文を表示
- ストーリーの4択クイズと結果表示、再挑戦
- 答え合わせ後に正解・例文を確認してから進むストーリークイズ
- Again / Hard / Good / Easy の自己評価に応じた間隔反復（再出題予定を保存）
- 「今日の復習」で苦手語・期限の来た語を優先し、意味・リスニング・スペルの練習モードを選択
- 中学・高校語彙の10問レベル診断と、次に取り組む学習コースの提案
- 受験コース、1日3〜20問の目標、連続日数、週次学習数、レベル別習熟状況
- 単語ごとに「覚えた」「まだ不安」を設定し、SQLiteに保存
- 学習状況と復習予定を匿名学習者IDごとにSQLiteへ保存
- ストーリー全体・本文中の単語・ことばメモから Web Speech API で英語を読み上げ
- CMUdict由来の米語IPA表記、読み上げ音声の選択、速度設定
- 中学・高校レベルと章を切り替えて読める複数のストーリー
- 全語彙を検索・レベルや暗記状態で絞り込める単語帳（ストーリー画面と状態を共有）
- スマートフォンにも対応したレイアウトとキーボード操作可能なボタン

現在は中学・高校の語彙・熟語902語（中学406語＝高校入試の頻出語彙、高校496語＝大学入試の頻出語彙。うちストーリー5編の対象語72語）を収録しています。151語は、東京外国語大学投野研究室の「CEFR-J Wordlist Version 1.6」A1/A2レベルから選定し、意味・例文・訳文はこのアプリ用に編集しています。同リストは日本の学校教育での相当レベルをA1=小学校〜中学1年程度、A2=中学2年〜高校1年程度としています。選定語はその目安を参考に中学レベルへ分類しています。902語すべてに、米語IPAを付けています（当初分はCMUdictの発音をもとにした表記、追加分は同じ表記法で編集）。

文部科学省の学習指導要領は学習する語数の目安を示していますが、本アプリは現行の全教科書・自治体別教材との照合をしていません。語彙の完全網羅、公式認定、受験範囲の保証を示すものではありません。CEFR-J Wordlistにも誤りや不完全な箇所があり得る旨が明記されています。読み上げ音声の種類や利用可否はブラウザー・OSの音声設定に依存します。

語彙の出典: 東京外国語大学投野由紀夫研究室 (2020), *The CEFR-J Wordlist Version 1.6*, [CEFR-J Resources](https://www.cefr-j.org/download.html)（2026年11月14日閲覧）。出典の利用条件に従い出典を明記しています。同リストの著作権は同研究室に帰属し、適切な引用を条件に研究教育・商用で無償利用可能とされています。学習範囲の基準: [文部科学省「学習指導要領・学習指導要領解説」](https://www.mext.go.jp/a_menu/shotou/new-cs/1384661.htm)。

発音表記の出典: [CMU Pronouncing Dictionary (CMUdict)](https://github.com/cmusphinx/cmudict) のARPAbet発音をIPAへ変換し、アプリ収録語に対応づけました。複数発音がある場合は辞書の先頭候補を採用しています。変換後の表記は米語の幅広い音素表記で、英国発音との違いや個別の音声合成品質を保証しません。ライセンス全文は `CMUDICT-LICENSE.txt` に記載しています。


## 静的版（GitHub Pages 用）

このリポジトリのルートにある `index.html` は、サーバーなしで動く静的版です。語彙902語とストーリー5編を1ファイルに収め、学習記録は端末のブラウザー（localStorage）に保存します。GitHub Pages を有効化すれば、そのまま公開URLで開いて使えます。間隔反復の計算はサーバー版と同一仕様です。サーバー版（この README の上の説明）は、複数端末での記録共有や本格運用のためのものとして併せて残しています。

## GitHub とデプロイ

GitHub Actions は Node.js 24 でデータ投入・テスト・型チェック・本番ビルドを実行します。このアプリは SQLite を使う動的な Next.js アプリのため、GitHub Pages のような静的ホスティングでは学習APIと進捗保存が動きません。公開リポジトリから Node.js サーバー対応のホスティングへデプロイしてください。Node.js の対応バージョンは22.13以降です。ホスティング先では永続ディスクを用意し、`DATABASE_PATH` でSQLiteの保存先を指定してください。

## データの追加

- `data/vocabulary.json` に語彙（`id`, `term`, `level`, `importance`, `meaning`, `translation`, `example`, `exampleTranslation`）を追加します。`id` は小文字英数字とハイフンの安定した識別子です。seed処理は500件単位でupsertするため、大量データも繰り返し投入できます。
- CEFR-Jから選定した中学レベルの補足語彙は `data/vocabulary-cefr-j.json` にあります。`term`, `meaning`, `example`, `exampleTranslation` が必須で、`id`, `translation`, `importance` は省略できます。`id` を省略すると `cefr-j-` を付けた安定IDを生成します。これらの語彙は単語帳・今日の復習に表示され、ストーリーの対象語にする必要はありません。
- ストーリーの対象語を含む補足語彙は `data/vocabulary-stories.json` にあります。`id` はストーリー側の `targetVocabularyIds` と一致させます。
- `data/stories.json` にストーリー（`id`, `level`, `chapter`, `title`, `readingTime`, `targetVocabularyIds`, `targetTerms`, `paragraphs`）を追加します。
- `targetVocabularyIds` は語彙データの `id` と一致させます。既存画面/API互換の `targetTerms` も同じ順序・件数で記載し、各対象語を本文に含めてください。seed時にID・用例・本文との整合性とストーリー語数を検証します。
